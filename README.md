# Cryptography & Data Protection

A structured repository for learning, researching, and practicing cryptography, network security, and data protection topics.

---

## 📁 Repository Structure

- [**01_Information_Security**](./01_Information_Security/README.md) - Core concepts, CIA Triad, threat modeling, and defense principles.
- [**02_Classical_Cryptography**](./02_Classical_Cryptography/README.md) - Historical ciphers (Caesar, Vigenère, Playfair, Hill, Enigma).
- [**03_Cryptanalysis**](./03_Cryptanalysis/README.md) - Frequency analysis, linear/differential cryptanalysis, brute-force, side-channel attacks.
- [**04_Symmetric_Cryptography**](./04_Symmetric_Cryptography/README.md) - Block & stream ciphers (DES, 3DES, AES, ChaCha20) and block cipher modes (ECB, CBC, GCM).
- [**05_Asymmetric_Cryptography**](./05_Asymmetric_Cryptography/README.md) - Public key cryptography (RSA, Diffie-Hellman, ECC, Post-Quantum).
- [**06_Hashing_MAC**](./06_Hashing_MAC/README.md) - Cryptographic hash functions (SHA-2, SHA-3) and MACs (HMAC, CMAC).
- [**07_Digital_Signatures_PKI**](./07_Digital_Signatures_PKI/README.md) - Digital signature algorithms (RSA-PSS, ECDSA, Ed25519), X.509 certificates, and PKI hierarchy.
- [**08_Network_Security**](./08_Network_Security/README.md) - Network protocols, ARP/DNS spoofing, packet inspection, and IPsec.
- [**09_TLS_HTTPS**](./09_TLS_HTTPS/README.md) - TLS 1.2 vs TLS 1.3 handshake, cipher suites, certificate validation, and HTTPS config.
- [**10_VPN_Firewalls_IDS**](./10_VPN_Firewalls_IDS/README.md) - VPN implementations (OpenVPN, WireGuard), stateful firewalls, IDS/IPS (Snort, Suricata).
- [**11_Data_Protection_Privacy**](./11_Data_Protection_Privacy/README.md) - Data-at-rest & in-transit, GDPR/HIPAA compliance, tokenization, anonymization, and differential privacy.
- [**12_Web_Security**](./12_Web_Security/README.md) - OWASP Top 10, XSS, CSRF, SQLi, SSRF, and security headers (CSP, HSTS, CORS).
- [**13_Secure_Software_Development**](./13_Secure_Software_Development/README.md) - SSDLC, SAST/DAST, input sanitization, safe crypto APIs, and dependency auditing.
- [**14_Blockchain**](./14_Blockchain/README.md) - Cryptographic primitives in distributed ledgers, Merkle trees, consensus mechanisms, smart contract security.
- [**15_Cloud_Security**](./15_Cloud_Security/README.md) - IAM, zero trust, cloud KMS, encrypted object storage, container security.
- [**16_Malware_Analysis**](./16_Malware_Analysis/README.md) - Static and dynamic analysis, ransomware encryption mechanics, sandboxing, and reverse engineering.
- [**17_Ethical_Hacking**](./17_Ethical_Hacking/README.md) - Penetration testing methodologies, vulnerability scanning, exploitation frameworks, reporting.
- [**18_Case_Studies**](./18_Case_Studies/README.md) - Real-world security incidents, historical breaches, and lessons learned.
- [**99_Resources**](./99_Resources/README.md) - Cheatsheets, reading lists, tools, labs, and reference links.
